## 30. Reset de contrasena

El reset de contrasena corporativa se realiza desde el portal de identidad. La nueva clave debe tener al menos 14 caracteres, un numero, una mayuscula y no puede repetir las ultimas 8 claves. Si el usuario no puede acceder al portal, Soporte valida identidad y genera un enlace temporal de 30 minutos. Despues del reset se recomienda cerrar sesiones activas.

## 31. Correo corporativo

Los problemas de correo se clasifican en acceso, envio, recepcion, phishing o configuracion de cliente. Para acceso se revisa estado de cuenta y 2FA. ## 36. Conexion VPN

Para problemas de VPN se debe verificar primero conexion a internet, estado del cliente VPN, version instalada y vencimiento del certificado. Si el error indica credenciales invalidas, el usuario debe reiniciar sesion despues de cambiar contrasena. Si el error indica tunnel timeout, se debe probar otra red y registrar latencia. Los incidentes de VPN que bloquean trabajo critico se clasifican prioridad alta.

## 37. Doble factor de autenticacion

El 2FA es obligatorio para correo, VPN, CRM, repositorios y consola de administracion. Si el usuario cambio de telefono, Soporte valida identidad con documento interno y aprobacion del lider.
